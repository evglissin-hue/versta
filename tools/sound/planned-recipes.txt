Target recipes for src/audio/soundscapes.ts, for when the recordings in tools/sound/sources.json have been fetched.

Steps: run `build_sounds.py fetch`, `process`, `check`, `credits`; copy the real effect lengths into catalogue.json; then
replace the RECIPES entries in soundscapes.ts with the ones below (loop names are the `name` fields of sources.json:
water, gulls2 and river replace the old water and gulls if wanted). Re-add this helper next to R and P:

  /** A sparse one-shot: effect `fx` every `every[0]` to `every[1]` seconds. */
  const S = (fx: string, every: [number, number], level: number, pan?: number): Part => {
    const p: Part = { fx, every, level };
    if (pan !== undefined) p.pan = pan;
    return p;
  };

Layers whose loop is not in sources.json (rigging, cobbles, tunnel, waders, sail-flap, oars, tankards and the like) had no
candidate under the licence bar: delete those parts, or keep their `gen` stand-in. Wading birds could use the CC BY 4.0
oystercatcher or greenshank recordings on Commons (W HAEMATOPUS OSTRALEGUS R4 C7, W TRINGA NEBULARIA R1 C4). Every
sparse layer must stay at least 6 dB under the base (tests/unit/sounds.test.ts checks level <= half the base).
