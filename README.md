# Versta

Rides and walks that tell you their stories as you pass. See `CLAUDE.md` for how the project is laid out and built.

- `npm install`, then `npm run dev` to run it locally. Add `?sim=1&speed=5&scale=8` to ride with the built-in simulator.
- `npm run check` runs the typecheck, lint, unit tests and the production build. `npm run e2e` runs simulated rides.
- Cloudflare Pages: build command `npm run build`, output directory `dist`.
